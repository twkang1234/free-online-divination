01、梅花易數問卦，最少應該記下哪些資料？

最少記六類：問題、時間、起卦方法、原始資料、卦象算式、後續核對。

不用一開始就記滿艱深術語。先做到「另一個人看完紀錄，知道你問什麼、何時起卦、用哪個方法，能不能把本卦和動爻重算出來」。進一步再記體用、互卦、變卦與實際發展。

生活故事｜你還記得上星期那一卦怎麼來的嗎？

小宜上星期收到朋友的合作邀約，起完卦只拍下卦名。今天想比較當時的判斷，卻想不起來當初報的是4和2，還是2和4；是先求工作，還是問合作；甚至忘了是不是同一時間又算過一次。紀錄的目的，不是讓占卜看起來更神祕，而是避免這些資料全部混在一起。

02、先列清楚：完整問卦紀錄的九個欄位

欄位需要寫什麼為什麼重要
1. 問事問題具體問題與時間範圍防止事後改成另一個問題
2. 角色本人問、代別人問、所問對象分清問卦主體
3. 起卦日期、時間年月日、時分、時區保留起念與取時的脈絡
4. 起卦法兩數法、年月日時法、字占等不同方法不能混算
5. 原始輸入數字、聲數、原字、外應等讓他人可以重新驗算
6. 卦象與算式上卦、下卦、本卦、動爻檢查算法是否正確
7. 體用與互變體卦、用卦、互卦、變卦分清不同判讀層次
8. 當下解讀當時的判讀與不確定點不要事後重寫自己的原判斷
9. 後續核對實際事件、日期、是否吻合保留未應驗及無法驗證的情況

初學者若覺得欄位太多，可以先填1～6項，再逐步補7～9項。這套是現代教學用紀錄模板，不是宣稱《梅花易數》古籍有一張逐字一模一樣的制式表格。

04、完整示範：用4、2替合作邀約起一卦

現在假設小宜想問：「接下來一個月，適不適合接受朋友一起辦活動的合作邀約？」為了示範記錄方法，她採現代兩數簡式，依序固定第一數4、第二數2。下列時間與人物都是教學假設，不是實際占驗紀錄。

① 原始數字：4、2

第一數4取上卦震（雷），第二數2取下卦兌（澤）。

② 本卦：雷澤歸妹

上震下兌，不能把4和2交換成澤雷隨。

③ 4＋2＝6，取第六爻

總數整除六，所以是上爻動，不是「沒有動爻」。

④ 變卦：火澤睽

上震由下而上為陽、陰、陰；最上爻陰變陽，震成離火，得火澤睽。

⑤ 體用與互卦

上卦動為用，下兌金為體，上震木為用，金克木，屬體克用；互卦為水火既濟。

䷵
本卦｜雷澤歸妹

上震下兌、上爻動

䷥
變卦｜火澤睽

上離下兌

這樣算完，你就有完整的「原始輸入 → 本卦 → 動爻 → 互變 → 體用」。接下來的判讀可以參考合作分工、資源與時間安排，但不能只憑一個關係就斷言這次合作必定成功或失敗。

05、把這個案例填進紀錄表，長這樣

【梅花易數問卦紀錄｜教學虛擬案例】
紀錄編號：DEMO-001
問事問題：未來一個月，是否適合接受朋友合作辦活動？
問事人／所問對象：小宜本人／合作邀約
起念時間：未單獨紀錄
正式起卦時間：2026-11-23 19:00（臺灣時間，示例）
起卦方法：現代兩數簡式
原始資料：第一數4、第二數2（事先固定）

第一數4 → 上震（雷）
第二數2 → 下兌（澤）
本卦：雷澤歸妹
總數4＋2＝6 → 第六爻動
互卦：水火既濟
變卦：火澤睽
體卦：下兌金；用卦：上震木
本卦體用：體克用（金克木）

當下解讀：合作議題需要確認角色與分工。
不確定點：尚不知道對方實際預算及人力安排。
下一步行動：詢問合作條件、時間與費用。
事後核對日期：待定
實際結果：尚未發生，不預填。
是否吻合：尚無證據，不能評定。

最重要的是最後兩行：現在還不知道結果，就寫「待定」。不要因為示範起了一卦，就編造它後來應驗的故事。

06、什麼是「可重算」？簡單檢查這四件事

  1. 第一數、第二數與順序都還在：數字順序改變，通常本卦也會變。
  2. 上下卦有寫出除八結果：4對震、2對兌；整除八時取坤8。
  3. 動爻能從總數重算：4＋2＝6，第六爻動；整除六不當作0。
  4. 變卦只翻動那一爻：雷澤歸妹上爻變，才得到火澤睽，而不是把整個卦隨意換掉。

如果你手邊只有「雷澤歸妹」四字，卻缺少最初的數字與動爻，就無法完整重算。這也是為什麼紀錄原始資料比背很多卦名更重要。

延伸練習可參考兩數起卦公式、體用判別和相同數字排錯清單。

07、紀錄時要把「卦象事實」和「解讀推測」分開

「4、2得到雷澤歸妹、上爻動」是按所選公式可以重算的演算結果；「這份合作可能有分工壓力」則是依卦象與問事語境作出的詮釋。兩者不應記在同一格，否則容易把自己的想法當成算出來的事實。

應寫在哪欄例子
公式／可驗算4＋2＝6；第六爻動；雷澤歸妹變火澤睽
傳統判讀下兌金為體，上震木為用，體克用
現代情境推測可能需要確認合作責任與資源
已查到的現實資訊對方還沒有提供活動經費表

將這幾欄分開，才不會事後知道結果後，把原來的解讀悄悄改寫成「當時早就預言到了」。

08、事後要怎麼核對，才不會只記住「有準」的卦？

到了原本設定的時間範圍，例如一個月後，回到同一張紀錄，增加三種資訊：有發生的事、沒有發生的事、還無法證實的事。若原問題本來就沒有清楚的衡量標準，也要直接註記不能判斷。

例如本例若最終沒有接下合作，不能直接宣稱「卦已應驗」；應另外註明是自己拒絕、對方取消、預算不足，還是另有原因。一張好紀錄不只保存覺得準的部分，也保存誤差與不確定。

記錄外應時也要附上觀察時點與最初的原話，不要事後補進本來沒有注意到的事情。這一類更深入的核對方法，可以延伸到第031篇「相同數字算出不同卦」，先把起卦資料核對清楚。

09、新手最容易漏記的六件事

  1. 只記卦名，不記原始數字、字形或時間。
  2. 只寫「問工作」，沒有清楚描述問的是哪個選擇和期限。
  3. 沒有註明使用兩數法、年月日時法或其他起法。
  4. 漏掉動爻，導致體用和變卦都無法回推。
  5. 把當下直覺與已經發生的事混寫，事後無法核對。
  6. 只保存符合期待的結果，沒發生或不確定的資料全部刪掉。

不必每次寫成長篇論文。固定一張模板，每次填寫同樣欄位，反而更省時間，也更能看出自己的方法是否一致。

10、最後記住：一份好紀錄，讓你能重算，也能回頭檢查

第一次練梅花易數，先別急著追求華麗的解卦文字。把問題、取數、時間、方法、本卦、動爻、互變、體用、當下判讀寫好，再留一格給後來的現實結果，已經比只存下一張卦圖扎實得多。

本篇提供的是現代練習模板，不是古籍原有的定型表格。等你有了十幾份紀錄，就能更容易檢查算式與思路，而不是只憑印象說「那次好像很準」。

11、常見問題 FAQ

梅花易數新手第一次起卦，最少要記什麼？

至少記具體問題、起卦時間、取卦方法、原始數字或字形、上下卦與動爻、實際演算結果；若要事後核對，再加入當下解讀與後續事實。

只記本卦名稱，不記動爻可以嗎？

不夠完整。缺少動爻就無法重建變卦與原本體用主客，也較難檢查整個起卦過程。

問卦紀錄需要寫姓名、生日等個資嗎？

一般演算練習不需要記錄無關的敏感個資。若有代問情境，可用角色代稱分清問事人與所問對象，資料以能核對問題為原則。

梅花易數有古籍規定的固定問卦紀錄表嗎？

本文的九欄是現代教學與自我驗算的建議模板，不能宣稱是《梅花易數》古籍逐字指定的格式。

4和2起卦為什麼是雷澤歸妹，上爻動？

4取上震、2取下兌，得雷澤歸妹；4＋2＝6，除六整除取第六爻；上震最上爻由陰變陽成離，故變火澤睽。

同一卦可以事後修改原始問題嗎？

不建議。當下問題與原始數字應保留不變；後來想到的新角度可加註，而不是覆蓋原始紀錄。

如果問卦後事件還沒發生，紀錄要怎麼寫？

在事後核對欄寫待定、未發生或資料不足，不能把想像的結果當成已應驗的事實。
