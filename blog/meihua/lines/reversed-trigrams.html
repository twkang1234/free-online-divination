山澤損和澤山咸都包含艮山、兌澤，為什麼不是同一卦？這篇固定7、2與2、7兩個例子，比較六爻、動爻、互卦、變卦和體用方向，還會釐清上下經卦交換和六爻倒序的差別。

01、山澤損與澤山咸，只差上下交換嗎？

從經卦組成看，是的：山澤損是「上艮山、下兌澤」；澤山咸是「上兌澤、下艮山」。上下位置一交換，已是另外一個六畫卦，不能把它當成同一卦的另一種寫法。

換了位置，不只卦名不同；本卦六爻排列、互卦、指定動爻後的變卦，以及體用主客關係，都可能跟著改變。

生活故事｜山在上、澤在下，真的跟澤在上、山在下一樣嗎？

子晴正在考慮要不要和朋友一起租空間辦工作坊。看到「山澤損」時，她以為朋友說的「澤山咸」也差不多，反正不都是山跟澤嗎？等到她把上下卦畫出來，才發現位置一變，整張卦的名字和後續推算都不同。

這篇只比較山澤損與澤山咸這一組特定的上下交換。如果想知道一般兩數交換有哪些影響，請讀第030篇兩數交換實算，兩篇各有不同教學用途。

02、先認識山與澤：艮七、兌二，位置要寫完整

梅花易數常用先天八卦數：艮為7，兌為2。但「艮」「兌」各是哪一半，不能只寫兩個卦名就省略位置。

完整本卦上卦下卦簡單記法
山澤損 ䷨上艮山（7）下兌澤（2）山在澤上
澤山咸 ䷞上兌澤（2）下艮山（7）澤在山上

「山澤損」與「澤山咸」是兩個不同卦名。先確認上、下卦，再讀完整卦名，比只記「山澤」兩個字不容易搞錯。注意，這裡是在講交換上下經卦的位置，不是把六條爻逐條倒讀。

03、上下互換後，六條爻真的哪裡不同？

六爻由最下方初爻向上排列。艮卦從下往上是「陰、陰、陽」，兌卦從下往上是「陽、陽、陰」。因此同樣兩個經卦，上下放法不同，六爻順序就完全不同。

由下往上山澤損澤山咸
初爻陽陰
二爻陽陰
三爻陰陽
四爻陰陽
五爻陰陽
上爻陽陰

看到這張表，就知道為何「把上卦跟下卦換位置」不是只是卦名寫法改了。它產生另一個不同的六畫排列，所以後續的互卦、變卦必須重新按新的本卦畫。

04、完整例子A：7、2先成山澤損

假設子晴本次採的是前面幾篇已使用的兩數簡式：第一數7作上卦、第二數2作下卦，兩數相加除六取動爻。

檢查欄位山澤損的結果
上卦7÷8餘7 → 艮山
下卦2÷8餘2 → 兌澤
本卦上艮下兌 → 山澤損（䷨）
動爻7＋2＝9，9÷6餘3 → 第三爻動
變卦下兌的第三爻原為陰，翻陽後下卦變乾 → 山天大畜（䷙）
體用第三爻在下兌：下兌金為用，上艮土為體 → 體土生用金
互卦本卦2、3、4爻取震；3、4、5爻取坤 → 地雷復（䷗）

這個例子是在練習先寫對上下位置，再算本卦的互與變。山澤損可以從「減少、調整、取捨」理解為傳統卦名的聯想，但若問租空間，不代表占卜已證明一定要縮減預算；實際仍須查契約與成本。

05、完整例子B：2、7換位成澤山咸

再用第二組獨立的教學輸入：第一數2、第二數7。這裡不是把上一卦看到結果後改掉，而是用「上下交換」做清楚的技術比較。

檢查欄位澤山咸的結果
上卦2÷8餘2 → 兌澤
下卦7÷8餘7 → 艮山
本卦上兌下艮 → 澤山咸（䷞）
動爻2＋7＝9，9÷6餘3 → 第三爻動（和前例相同）
變卦下艮的第三爻原為陽，翻陰後下卦變坤 → 澤地萃（䷬）
體用第三爻在下艮：下艮土為用，上兌金為體 → 用土生體金
互卦本卦2、3、4爻取巽；3、4、5爻取乾 → 天風姤（䷫）

傳統「咸」常連想到感應、互相影響。若問合作關係，可以把它當作提醒：除了財務，也要確認彼此溝通與期待。但這種象意是傳統占斷的解讀素材，不是直接測得另一個人的情緒或承諾。

06、兩卦一張表對照：動爻相同，其他結果仍不同

7、2｜山澤損

䷨ → ䷙

上艮山，下兌澤

第三爻動：變山天大畜

體艮土生用兌金

互卦：地雷復

2、7｜澤山咸

䷞ → ䷬

上兌澤，下艮山

第三爻動：變澤地萃

用艮土生體兌金

互卦：天風姤

核對項目7、22、7
上卦艮土兌金
下卦兌金艮土
本卦山澤損澤山咸
動爻第三爻第三爻
互卦地雷復天風姤
變卦山天大畜澤地萃
體用體生用用生體

重點在這裡：兩數總和一樣，所以本篇採用的動爻位置都在第三爻；但第三爻原來的陰陽不同、所屬經卦也不同。因此不能只因動爻數字相同，就判變卦、互卦也一定相同。

07、「上下卦交換」不是「整個六爻倒過來看」

這個名詞常被混淆。你可以把上下兩個三爻卦想成上下兩張卡片：交換卡片位置，卡片內部三爻次序不改，就是我們這篇的上下卦交換。

但若將原來的六條爻從上到下逐條反過來排列，那是另一種操作。以山澤損來說：

操作實際怎麼做得到的卦
上下經卦交換艮上兌下 → 兌上艮下澤山咸
六爻次序整體倒置六條爻順序逐一反轉再重新分上、下卦風雷益

所以不要把「山澤損的上下卦交換後是澤山咸」寫成「山澤損整個卦倒過來就是澤山咸」。兩種動作不是同一回事，後者在技術上會得到不同卦形。

08、把兩個卦的象意放進生活情境，怎樣才不硬套？

例子｜一起租空間辦工作坊

若子晴想問「和朋友租空間合作，有哪些事要先講清楚？」看到山澤損，可先從傳統「有所取捨」的意義出發，檢查租金、設備、宣傳預算哪些項目能調整。看到澤山咸，可從「互相感應、互相影響」出發，檢查雙方的責任分工與溝通方式。

兩個卦的生活比喻不是「損一定破財、咸一定戀愛成功」的保證。你仍應先確認當次起卦原始數字、動爻、體用，接著才在問題的範圍內選擇合適的象意。

如果想專門學「一個卦有很多象意時如何取捨」，可以留待第039篇深入討論；本篇先把上、下位置對算式造成的影響看清楚。

09、三個自己能重算的小題目

  1. 山澤損與澤山咸，哪個是上艮、下兌？
  2. 7＋2與2＋7的總和相同，那第三爻動後會得到同一個變卦嗎？
  3. 山澤損如果把六條爻順序全部倒置，還是澤山咸嗎？
點擊看完整答案

① 山澤損是上艮下兌；澤山咸則上兌下艮。② 不會。山澤損第三爻原陰翻陽，得山天大畜；澤山咸第三爻原陽翻陰，得澤地萃。③ 不是；六條爻逐條倒序後得風雷益。上下經卦整組交換才得澤山咸。

如果你算不出變卦，先回第032篇確認單動爻的算法；如果你只想比較交換兩個輸入數字的一般情況，可讀第030篇。

10、本次算式怎麼記錄，才不會混成另一個卦？

遇到上下卦顛倒的情況，把這五欄一起保存，日後就比較不會看到相似卦名卻對不上：

新手核對格式

① 第一數＿＿，作上卦＿＿
② 第二數＿＿，作下卦＿＿
③ 本卦＿＿，六爻由下往上＿＿
④ 動第＿＿爻，變後上下卦＿＿，變卦＿＿
⑤ 本體＿＿、本用＿＿、互卦＿＿

只要寫出上、下兩個字，很多表面上很神祕的差異，其實就能回到哪個位置放錯了。真正要追問何以判吉凶，則是另一個進階學習主題。

常見問題 FAQ

山澤損和澤山咸是同一個卦嗎？

不是。山澤損是上艮山、下兌澤；澤山咸是上兌澤、下艮山。上下經卦位置互換，就已形成不同的完整六爻卦。

山澤損上下卦交換後，會變成什麼？

把上艮、下兌兩個經卦整組交換，變成上兌、下艮，即澤山咸。這不是說把六條爻逐條倒置。

山澤損第三爻動，變什麼卦？

原下兌第三爻是陰爻，翻成陽後下卦變乾，得上艮下乾的山天大畜。

澤山咸第三爻動，變什麼卦？

原下艮第三爻是陽爻，翻成陰後下卦變坤，得上兌下坤的澤地萃。

7、2和2、7的動爻為什麼一樣，變卦卻不同？

兩組總和都是9，除六餘3，所以都指定第三爻。但本卦上下位置不同，第三爻陰陽不同，因此變後經卦與變卦不同。

上下卦交換與把六條爻整個倒過來是一樣的嗎？

不是。山澤損把上艮下兌整組交換，得澤山咸；把六條爻的上下排列逐一倒置，得到的是風雷益。
