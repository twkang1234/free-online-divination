多字起卦怎麼算？字數分組、筆畫與聲調法比較

你想知道接下來該不該主動和朋友談談，順手寫下「安心」；過幾天又寫了「平安順利」。兩個字、四個字，算卦方式會一樣嗎？答案是：不一定。今傳《梅花易數》卷一對不同字數有不一樣的分組與取數方式。這篇把規則拆開，用幾句生活中真的會寫的話帶你算一遍，不用先背一整本古書。

一、多字起卦的重點：先數字數，再決定算法

今傳《梅花易數》卷一的多字占，不能一律用「全部文字筆畫相加」。

兩字、三字有分字與筆畫取數的做法；四至十字另有傳統平、上、去、入四聲取數；十一字以上改用字數分組。這篇分開示範，不將後世現代國語聲調直接冒充古四聲。

生活場景｜一樣是寫一句心裡話，字數會改變取法

「安心」是兩字；「我想學」是三字；「平安順利」是四字。傳統字占的關鍵是先固定你寫下的字串，再依該段條文決定怎樣分組，而不是看到結果不喜歡就重新換詞。

字數上下卦如何分本文用什麼取數
2字第一字上、第二字下各字筆畫數
3字第一字上、後兩字下各組筆畫合計
4～10字偶數平分；奇數上少一字、下多一字古四聲平1、上2、去3、入4
11字以上偶數平分；奇數上少一字、下多一字各組字數，不再用古四聲

一字的左右筆畫拆法請讀第012篇｜梅花易數一字起卦。下面從兩字開始，先選最能自己核對的例子。

二、分組前先確認：卦除八、爻除六

字占會遇到兩種數字：上組的數與下組的數。上組除八取上卦、下組除八取下卦；兩組數合計除六取動爻。餘數0時，八卦當坤8、動爻當第六爻。

餘數八卦常見記法
1 / 2乾 / 兌☰ / ☱
3 / 4離 / 震☲ / ☳
5 / 6巽 / 坎☴ / ☵
7 / 0艮 / 坤☶ / ☷（0按8）

注意：「分字」只是決定各組包含什麼字，真正用哪種數字還得看字數段落。兩三字的筆畫，不能隨手改成四字法的古四聲；四字的古四聲，也不能突然改成現代國語一到四聲。

三、兩字起卦完整示範：「安心」怎麼算？

先寫下兩字「安心」，假設這是你想練習整理心情的題目。用繁體楷書筆畫：安6畫、心4畫。依兩字平分，一字一卦。

取法算式得到
上卦安6畫；6÷8餘6坎☵
下卦心4畫；4÷8餘4震☳
動爻6＋4＝10；10÷6餘4第四爻
變化上坎的最下一爻陰變陽，上卦成兌澤雷隨（17）
䷂
本卦：水雷屯（3）

上坎☵、下震☳，第四爻動。

䷐
變卦：澤雷隨（17）

翻第四爻，上坎變兌，下震不變。

「安心」兩字：安6→上坎，心4→下震，10除6餘4 → 水雷屯四爻動，變澤雷隨。

這是一套指定筆畫規則下可驗算的教學卦例；不是說寫下「安心」就必然會發生某種結果。

四、三字怎麼分？「我想學」的一字上、兩字下

如果字數是奇數，今傳字占條文採上組少一字、下組多一字。三字時，就是第一字上卦、後兩字下卦。以繁體「我想學」為例：

組別字與筆畫合計與卦
上組「我」7畫7→艮☶
下組「想」13畫＋「學」16畫29÷8餘5→巽☴
動爻7＋29＝3636÷6餘0→第六爻
䷑
本卦：山風蠱（18）

上艮☶、下巽☴，第六爻動。

䷭
變卦：地風升（46）

上艮最上陽爻變陰，成坤☷；下巽不變。

這一例同時練到奇數分組與除六餘0＝上爻。不需要先背「三才」的所有象徵，你只要能從第一個字和後兩字正確分組，就會算了。

五、四至十字的關鍵：不是數筆畫，而是古四聲

今傳卷一在「四字為四象」之後，說四字以上可以不再數筆畫，改用平、上、去、入四聲取數：平1、上2、去3、入4；直到十一字以上又改成只用字數。

先用四字「平安順利」作練習

此例採傳統聲調分類：平（平1）、安（平1）、順（去3）、利（去3）。四字平均分，上兩字、下兩字。

項目古四聲取數結果
上組「平安」1＋1＝2兌☱
下組「順利」3＋3＝6坎☵
動爻2＋6＝8；8÷6餘2第二爻動
變卦下坎中間陽爻變陰，成坤☷澤地萃（45）
䷮
本卦：澤水困（47）

上兌☱、下坎☵；第二爻動。

䷬
變卦：澤地萃（45）

下坎中爻陽轉陰，變坤☷。

特別提醒：古四聲不是今天台灣國語的「第一聲1、第二聲2、第三聲3、第四聲4」直接對照。像「平」在古四聲歸平聲，今日國語讀第二聲；「國」「學」等古入聲字，現代普通話的聲調也不一定是第四聲。若沒有古音查核，不能假裝按今音就能復原古法。

六、若改用現代國語四聲，卦會一樣嗎？

有人會把現代國語「一二三四聲」直接換成數字。這是一種現代改編的取數約定，不是上節古四聲的同一個算法。為了讓差異看得見，我們只做對照，不把它和古法混在同一次起卦。

同一詞「平安順利」古四聲示例現代國語聲調（另立約定）
平／安平1＋平1＝2→兌píng二聲2＋ān一聲1＝3→離
順／利去3＋去3＝6→坎shùn四聲4＋lì四聲4＝8→坤
動爻8÷6餘2→第二爻11÷6餘5→第五爻
卦與變卦澤水困→澤地萃火地晉（35）→天地否（12）

這正是為什麼搜尋「多字起卦」會看到不同算法。不同卦不代表字改變了命運，而是取數系統改變了。教學上，應先交代到底學的是古四聲，還是現代方便記憶的改編法。

七、十一字以上怎麼算？只按字數分組

今傳條文對十一字以上又有另一規則：不用古四聲，只數字數。若字數為奇數，上組少一字、下組多一字；上下兩組字數分別取卦，再合計取動爻。

例句：「今天想把這件事情說清楚」，不含標點共11字：

分組實際字串字數與卦
上組今／天／想／把／這5字→巽☴
下組件／事／情／說／清／楚6字→坎☵
動爻總數1111÷6餘5→第五爻
變化上巽第五爻陽轉陰，上卦成艮山水蒙（4）
䷺
本卦：風水渙（59）

上巽☴、下坎☵；第五爻動。

䷃
變卦：山水蒙（4）

上巽中爻變陰成艮，下坎不動。

若是12字，就分6字與6字。要特別注意：十一字以上的這一法，取的是字數，不是各字筆畫總和；也不是把每個字的現代聲調相加。

八、多字起卦常見問題

兩個字起卦，要把兩個字的筆畫加在一起嗎？

先分別取第一字與第二字的筆畫作上下卦，然後再以兩組數合計取動爻。不能直接用總筆畫同時當上下卦。

三個字的上卦、下卦各占幾字？

依今傳卷一三字規則，第一字為上組，後兩字為下組；先固定傳統楷書筆畫標準，再計算上下卦與動爻。

四字起卦一定要數每個字的筆畫嗎？

不是。今傳卷一四至十字的說法包括古四聲取數。需先分組，再按事先採用的古四聲分類換算，不要把兩三字筆畫法一概套用。

古代平上去入等於國語一二三四聲嗎？

不等於。古四聲與現代國語聲調的歷史演變不同，古入聲字不會都落在國語第四聲。現代聲調取數只能標示為現代另立方法。

十一字以上，還需要查每個字的聲調嗎？

依今傳卷一的十一字以上規則，不再用聲調，而是直接按字數分上下兩組，兩組字數合計再取動爻。

我起卦時多寫了一個字，可以事後刪掉嗎？

不建議為了換結果而事後改字。最好保留原句、字數與分組；確有筆誤時應重新記錄並說明原因。

九、新手容易混淆的四件事

  1. 把一字、二字和十字全部用同一個算法：卷一已按字數區分規則，先辨段落。
  2. 四聲沒有核對古音：國語二聲並不必然等於古上聲，否則本卦會不同。
  3. 分組順序改來改去：三字「一上兩下」，十一字奇數「上少下多」，不要出結果才反過來分。
  4. 把可算的卦形當成會發生的事件：象意推論要回到實際問題，和筆畫數、聲調分類分層。

還想繼續練習？

先讀第012篇｜一字起卦，熟悉左右筆畫；再到第006篇｜體卦用卦怎麼分、第010篇｜解卦完整教學，把起卦與判讀接起來。
